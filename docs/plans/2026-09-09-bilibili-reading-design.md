# Bilibili Reading Design

## Goal

让用户在 Discord 中通过 `@机器人 + B站链接/BV号 + 可选问题` 直接总结视频或基于字幕问答。

## Design

机器人先从消息中识别 `bilibili.com`、`b23.tv` 或裸 BV 号。短链接只跟随跳转以解析 BV 号，随后沿用 COROS Agent 的方式调用 B 站视频信息与字幕接口。凭据从一个独立 TOML 文件加载，部署时复用 COROS 现有凭据文件并设置为仅服务器用户可读；凭据文件、Cookie 和字幕均不写入 Git。

视频资料包含标题、UP 主、简介、时长和中文人工/AI 字幕。字幕经过密度与时间轴覆盖校验，避免 B 站偶发返回不属于该视频的错误字幕。过长字幕会采样到固定字符预算。模型收到的内容明确标记为不可信外部资料，只用于总结和回答，不能覆盖系统规则。

只发链接时默认生成概要、主要观点和结论；附带问题时按问题回答。没有字幕时仍可根据标题与简介回答，但必须说明未读取到字幕。Discord 进度展示解析链接、读取字幕和组织回答。B 站接口错误、凭据过期或风控会转成简洁错误，不进入普通网页搜索，也不伪装成已看过画面。
