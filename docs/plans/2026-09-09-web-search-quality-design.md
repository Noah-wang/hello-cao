# Web Search Quality Design

## Goal

让机器人在处理“今天的比赛表现”等时效问题时，不把赛前前瞻误当成赛后资料；资料不匹配时自动修正查询并重搜一次，同时允许预测类问题给出明确标注的主观预测。

## Design

现有关键词与语义路由继续负责判断是否联网。联网前先根据问题和当前日期生成搜索查询：体育赛后问题补充明确日期以及“全场比分、赛后战报、球员评分”；预测问题补充“近期状态、伤病、预计阵容”。首轮搜索后，用现有 LLM 做轻量 JSON 校验，判断来源是否匹配主题、日期和资料阶段。赛后问题若只得到赛前内容，视为不合格。

校验合格时直接把来源交给主回答。校验不合格时，使用校验器给出的修正查询调用 Monid，最多重搜一次，并在 Discord 进度消息中显示重搜状态。第二轮结果仍不合格时，不把误导资料交给主回答；事实问题进入“联网资料不足”降级，预测问题则允许依据有限信息作主观预测并明确其不确定性。

所有额外 LLM 校验请求均计入 Token 与预估费用。Monid 失败、校验器超时或返回非法 JSON 时，流程不会无限重试：保留首轮资料并让主回答明确说明限制。测试覆盖查询增强、赛前/赛后判定、自动重搜、预测降级和最多一次重搜。
